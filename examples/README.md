# サンプルプロジェクト

ツールバーの **開く** から読み込んでください。

| ファイル | 中身 |
|---|---|
| `alto-set.wproj` | アルトの一式（マウスピース＋リガチャー＋リード）。**すべてテンプレートの既定値** |

**これは推奨値ではありません。** 推奨値は
`saxsketch/instruments/saxophone/templates/alto.json` 側の仕事で、
このサンプルの仕事は「3 部品が揃ったセットはこう見えるか」を
新しく来た人に 1 クリックで見せることだけです。

`.wproj` は ZIP です。中身は `project.json` 1 枚
（外部編集で凍結したモデルがあれば `derived/<部品>/model.stl` も入る）。

## 作り直す

設計を変えたりスキーマを上げたりしたら、作り直してコミットし直してください。
**アプリ自身に作らせる** —— セットの約束（必須メンバー・役割・既定の選択）を
手で書き写すと、約束を変えた日にサンプルだけ古くなります。

```bash
# WSL2、リポジトリ直下から
wsl bash -lc "PYTHONPATH=. ~/mp_design/.venv/bin/python examples/make_example.py"
```
