# 実製作品の検品 — 届いた実物を測って設計へ返す

3Dプリントに出したマウスピースが届いたとき、**何を・どう測り・何と比べるか**を
先に決めておくためのシート。初回は 2026-08-23、アルト `AltoSaxSetTrial1.wproj`。

このシートの数値は**すべて対象の `.wproj` から計算したもの**で、手写しではない
（再計算の手順は末尾「数値の再生成」）。設計を変えたら作り直すこと。

図は `cad/windycity/measure_alto.svg`（どの寸法がどこか）を併せて見る。

---

## 0. 大前提 — なぜ印刷品だけでは足りないか

**印刷品を測って設計値と違っても、原因がプリンタか設計かは分からない。**

アルトのテンプレートで**実測に基づくのは 3 点だけ**（Wood Stone PHROX をノギスで
実測、2026-08-13）:

    全長 91.7 / ボア内径 15.8 / 最大径 29.1

残りは比で引いた推定値。軸方向の `bore_length` `window_length` `tip_rail_width` は
軸比 0.8530、径方向の `shank_dia` `beak_height` `side_rail_width` `baffle_height`
`rollover_radius` `tip_rail_thickness` `tip_chamfer` は径比 0.9167 を掛けただけ
（出所はテンプレート `alto.json` の `note`）。

だから **同じ手順で PHROX も測る**。3 列にすると差が分かれる:

| 差 | 意味 |
|---|---|
| 印刷品 − 設計値 | **印刷側**の誤差（収縮補正・積層・後処理） |
| PHROX − 設計値 | **設計側**の誤差（比で引いた推定値の外れ） |
| 印刷品 − PHROX | 実物同士の差。吹き比べの結果と直接つながる |

**実測は組で入れること。** 1 点だけ入れると、実在しない不足を記録することがある
（アルトのリード全長だけ先に入れて、テナーから借りたシャンク比 28% 過大が
判定を汚しかけた。2026-08-15）。

## 1. 入稿物の同定

測る前に、**何を測っているのか**を固定する。

| 項目 | 値 |
|---|---|
| プロジェクト | `AltoSaxSetTrial1.wproj` / `AS_reference_trial` |
| 保存 | 2026-08-22T13:08:03Z（22:08 JST） |
| 楽器 / テンプレート | saxophone / alto |
| 印刷した部品 | **マウスピースのみ** |
| 材料 | `resin`（光造形 SLA/DLP） |
| パラメータ | **alto テンプレートと 1 つも違わない** ＝ PHROX 校正の基準設計そのもの |

セットにはリガチャー（`band_width` 24.0 / `band_thickness` 2.0 / `seat_setback` 4.0）と
リード（`tip_thickness` 0.7 / `vamp_length` 42.0 / `filed`）も入っていて、こちらは
テンプレートから変更されている。**今回は印刷していないので検品対象外。**

### 入稿 STL の世代 — **修正後の細かい方で確定**（2026-08-23 実測）

4-D.5（`62c89cf`、2026-08-22 21:28 JST）で母線の刻みと `angular_tolerance` を
細かくした。修正前に出した STL なら胴の半径が法則より **0.083〜0.133mm 内側**に
あるので、入稿品そのものを測って決着させた。

対象: `…-20260822-220140/mouthpiece/model.stl`（753,684 bytes / 三角形 **15,072**）。
z 断面の交点から半径を出し、`profiles.outer_radius` の法則と比べた:

| 探り点 | 修正前の記録 | 修正後の記録 | **入稿品の実測** |
|---|---|---|---|
| z=58 | 0.078 | 0.026〜0.034 | **0.0055** |
| z=62 | 0.076 | 〃 | **0.0096** |
| z=66 | 0.167 | 〃 | **0.0066** |

丸い胴（窓より後ろ、z=38〜72）を 0.25mm 刻みで 137 断面走査して
**中央 0.0077 / 最大 0.0183mm**。修正前とは 1 桁違う。記録してある修正後の値より
さらに小さいが、あちらはリガチャー座の 3 点、こちらは連続走査なので測り方が違う
——どちらにせよ修正前ではない。

裏づけ 2 つ:

- **タイムスタンプ** —— `model.stl` は 8/22 22:01、4-D.5 のマージは同日 21:29 JST
- **形が現行モデルと一致** —— bbox が x ±14.5499 / y −12.7681〜+14.5455 / z 0〜91.7

**STL と 3MF は同じメッシュ**（どちらも三角形 15,072。3mf は頂点 7,536 の
共有インデックス）。「どれで作っても同じ形」は入稿した実物のファイルでも成立している。

## 2. 道具と分解能 — 測る前に読む

手持ちは **ノギス 0.05mm** と **チューナー＋アルト実機**、そして基準実物 PHROX。

- ノギス 1 回の読みの不確かさは **±0.05mm 級**。
  **0.1mm 未満の差は「差がある」と言ってはいけない。**
- **完璧なプリンタでも印刷品は設計値より細く出る。** STL は多角形近似だから。
  ただし**この個体は実測で 0.0055〜0.0183mm 内側**（**直径で 0.011〜0.037mm**）で、
  ノギス 1 目盛りの 1/3 以下。**ノギスで見えるずれが出たら、原因はメッシュではなく
  プリンタ側**（収縮補正・露光・後処理）と断定してよい。
- 判定帯は SaxSketch の採寸カードと同じ規則を使う
  （`mouthpiece.survey_card`: 一致 `max(0.6·step, 0.05)` / 軽微 `max(2.5·step, 0.2)`）。
  **新しいしきい値は作らない。**

**ボア長は「測れない」が記録済みの事実。** テンプレートの `note` に
「両ジョウとも円筒ボアの明確な終端が見えず測れなかったため、全長からの導出」と
ある。49.05 は `bore_length/overall_length` が soprano 0.5364 / tenor 0.5349 と
0.3% で一致することから引いた値で、**実測ではない**。

読み ±1 目盛りで判定が裏返るので、この 2 つは「一致/軽微」を出さず数字だけ記録する。

**採寸対象なのにこの表に無いのは `reed_width` 13.40 だけ。** これはノギスを当てる面が
無い（テーブルが受けるリードの幅であって、実物の稜線ではない）。**実物のリードを
載せて確かめる**ほうが正しいので §6 に置いた。

## 4. 測り方の落とし穴（実際に間違える 3 つ）

**① ボディ径はテーブルと平行に測る。**
最大径の位置 z=70.30 では**テーブルのカットがまだ生きている**（カットが胴から
外れるのは z=73.04）。テーブル面から反対側へノギスを当てると **27.12mm** しか
出ない。正解は横（テーブルと平行）に当てて **29.10**。
**差 1.98mm** ——間違えると「2mm 小さい」という誤報になる。

**② ウィンドウ長の起点はティップではない。**
窓の前縁はティップレールの後ろ、ティップから 0.73mm の位置。設計値 35.02 は
**窓の開口そのものの長さ**（ティップから 0.73 → 35.75）。

**③ 軸方向の基準が 2 つある。**
`facing_length` `window_length` は**ティップから**、
`bore_length` `cork_depth` `shank_length` は**シャンク端から**。
図（`measure_alto.svg`）も寸法線の向きでそれが読めるように描き分けてある。

## 5. いま測れないもの — と、それを開ける道具

**測れないのは「どう鳴るか」を決めている 3 つ**: ティップ開き・フェイシング長・
フェイシングカーブ。**隙間ゲージ（シックネスゲージ）1 本**で全部測れる。

設計カーブは算出済み。ガラス平面をテーブルに当て、ティップ側から隙間ゲージを
差し込んで**止まった位置をティップから測る**:

| 隙間 [mm] | ティップからの距離 [mm] |
|---|---|
| 0.05 | 19.66 |
| 0.10 | 18.28 |
| 0.15 | 17.22 |
| 0.20 | 16.33 |
| 0.30 | 14.83 |
| 0.50 | 12.46 |
| 0.75 | 10.09 |
| 1.00 | 8.11 |
| 1.50 | 4.78 |
| 2.00 | 1.98 |
| 2.40 | 0.00（＝ティップ開き） |

（`profiles.facing_rise` の円弧カーブを反転して算出。`facing_curve: radial`、
`facing_length` 23.0、`tip_opening` 2.4）

**隙間ゲージが無いあいだの代用**: ガラス板にテーブルを伏せて置き、ティップが
浮いた量をノギスの段差測定で読む（設計 2.40mm）。実力 ±0.1mm 程度で一致帯 0.05 には
届かないが、**0.3mm 級の異常なら捕まる**。

### オプション（安い割に効く）

| 道具 | 測るもの | 設計値 | 何が分かるか |
|---|---|---|---|
| はかり 0.1g | 重量 | **25.4g** | スケール誤差・中空化・硬化不足をまとめて捕まえる |
| 注射器 10ml | 内部容積 | **13.77cc** | 空洞が設計どおりか（Tier1 の入力そのもの） |

重量はソリッド体積 22.12cc × レジン密度 1.15 g/cc。
容積はシャンク端を上にしてテーブルをガラスで塞ぎ、シャンクから注水して満たす。
**スケール誤差は体積では 3 倍に出る**（線寸法 1% ＝ 質量 3%）ので、
0.1g のはかりでもノギスより鋭い。

## 6. 篏合チェック（道具不要・○×で足りる）

| 見るところ | 設計の狙い | 出所 |
|---|---|---|
| ネックに入るか | ボア 15.80 に対しテノン 14.5 ＋ コルク 0.75×2 ＝ 16.0。**締め代 0.20mm** | ネック実測（Yamaha YAS-875、2026-08-09） |
| どこまで入るか | 予測 13.6mm、**上限 36.4mm** | 上限は同じ PHROX を YAS-875 に押した実測 |
| 市販リガチャーが掛かるか | 最大径 29.1 / 受け上限 29.0 | PHROX（29.1）は実際に適合している |
| 市販リードが載るか | 先端幅 13.4 | 規格値。サイドレールに合うか、テーブルに密着するか（光にかざす） |
| 気密 | — | シャンクを塞いで吸う |

**締め代 0.20mm は設計に意図して入っている。** コルクが潰れる前提なので、
ボアが小さめに出ていると効きが倍になる。**入りにくければ無理に押さない**
——樹脂は割れる。入らなかったこと自体が最も価値のある報告になる。

なお締め代 0.2 の出所は**テナー 1 組だけ**で、同じネックに載る Meyer G 6番は
ボア 16.4（0.6mm 太い）。**締め代は 1 点ではない**（`reference_check.INTERFERENCE_FIT_MM`）。
このマウスピースが渋ければ、それはその 2 例目になる。

## 7. 吹奏テスト — **PHROX との A/B が本体**

モデルの予測:

    25°C で第1共鳴が D♭3 138.59Hz に合う挿し込み量  13.58mm
    感度                                          0.49 セント/mm
    実用域                                        3.0 〜 36.4mm

**絶対位置は弱い指標。** 0.49 セント/mm ということは、10mm ずれても 5 セントに
しかならない。しかも Tier1 の note が明記しているとおり、この値は**基準条件の
ものでリード・リガチャー・アンブシュアを含まない**。

だから **同じネック・同じリード・同じリガチャー・同じ日に PHROX と交互に吹き、
差を記録する**。差ならモデルに入っていない要素の大半が相殺する。

記録するもの:

| 項目 | 印刷品 | PHROX |
|---|---|---|
| リード（銘柄・番手・材質） | | |
| リガチャー | | |
| チューナー基準（A=◯Hz） | | |
| 室温 | | |
| 音が合ったときの挿し込み量 [mm] | | |
| 低音域のずれ [cent] | | |
| 中音域のずれ [cent] | | |
| オクターブ上のずれ [cent] | | |
| 発音（出るか・詰まるか） | | |
| 抵抗感（軽い / 重い） | | |

**挿し込み量の測り方**: 音が合った位置でネックのコルクに印を付け、外してから
印〜ネック小端の距離をノギスで測る。これが `cork_depth`（＝ネックがボアへ
入っている長さ）と同じ量で、上限 36.4mm もこの測り方の実測値。

## 8. 造形品質（写真で足りる）

- テーブル面の平面度 —— ガラスに載せて光漏れを見る（**リードが密着する面。
  0.01mm の段差でも雑音・鳴りに直結する**）
- サポート痕の位置 —— テーブルとティップレールに残っていないか
- ティップレールの欠け・潰れ
- 積層段差、反り、気泡、未硬化のべたつき・匂い

**多角形の紋様は既知で、篏合には効いていない。** この個体の実測で法則からの
ずれは最大 0.0183mm、設計クリアランスは 0.25mm ——1〜2 桁小さい（§1）。
写真に写っても異常ではない（詳細は `docs/manual-edit-workflow.md`）。

写真は 3 枚: **テーブル面を斜光で** / **ティップを正面から** / **全体の側面**。

## 10. 測ったあと

**既存の採寸（🔍 採寸）に印刷品の実測を入れてはいけない。**
`survey_commit` は実測値を**設計パラメータへ上書きする**（基準実物を写し取る
ための機能）。自分の印刷品でやると**プリンタの誤差が設計に焼き付き、次の出力が
二重にずれる**。

- **PHROX の実測** → 採寸に入れてよい（そのための機能）。ただし**組で入れる**
- **印刷品の実測** → いまは受け口が無い。このシートに書いて渡す

上書きしない「検品」経路を SaxSketch に足すかは、実測が出てから決める。
