# 手動編集ワークフロー — 外形・細部の個別調整

パラメータで表現できない調整（名入れ、フィレット、グリップ模様、有機的な曲面など）を
外部フリーツールで行うための標準手順。

## 基本原則

1. **パラメータで済む変更はパラメータで行う。**
   再現性（.wprojで完全復元）・シミュレーション整合・テンプレート再利用が保てる。
   「よく使う手動編集」はパラメータ化要望として吸収するのが最善（例: 名入れ文字）。
2. **音響に効く面は手動編集しない。**
   SaxSketch のシミュレーション（音程・音色・内容積）はパラメータから計算する。
   内部空洞やフェイシングを手で変えると、表示と実物が乖離する。
3. **手動編集は最終工程。**
   「パラメータ確定 → 凍結 → 外部編集 → 検査 → 入稿」の一方通行。
   凍結後にパラメータを変えたら、手動編集はやり直しになる（後述）。

### 触ってよい面 / いけない面

| 区分 | 面 | 理由 |
|---|---|---|
| ○ 編集可 | 外周面・シャンク外面・ビーク外面 | 音響への影響が小さい（beak_height の実効値は維持する） |
| △ 慎重に | ビーク先端付近・リガチャー座 | 咥え心地・リガチャー適合に影響。寸法を仕様書で確認しながら |
| × 禁止 | テーブル / フェイシング面 | リード密着面。0.01mm の段差でも雑音・鳴りに直結 |
| × 禁止 | ウィンドウ縁（レール） | 同上。レール幅はパラメータで変更する |
| × 禁止 | 内部空洞（バッフル・チェンバー）・ボア内面 | 内容積・音色がシミュ表示から乖離。パラメータで変更する |

## 編集レベルと使い分け

| レベル | 対象 | ツール（無料） | 形式 | 例 |
|---|---|---|---|---|
| **L0** パラメトリック | 全体 | SaxSketch | .wproj | ティップ開き、バッフル、全長… |
| **L1** ソリッド編集 | 外形の局所 | FreeCAD | **STEP** | エッジのフィレット/面取り、名入れ（彫刻）、装飾溝、平面カット |
| **L2** メッシュ彫刻 | 自由曲面・質感 | Blender / Meshmixer | STL/3MF | ビークの噛み心地、グリップ模様、有機的形状 |
| **L3** 印刷前処理 | 造形品質 | PrusaSlicer / OrcaSlicer | STL/3MF | 向き・サポート・中空化・スケール補正 |

判断基準: **STEP（L1）で済むなら STEP**。ソリッドのまま寸法精度が保たれ、後からの
再編集も容易。STL（L2）は自由に彫れるが寸法情報を失い後戻りできない。

## 標準フロー

```
SaxSketch         パラメータ設計・シミュレーション確定
   │              ① .wproj 保存（＝復帰点） ② STEP+仕様書エクスポート
   ▼
FreeCAD (L1)      外形の局所編集（フィレット・名入れ・溝）
   │              STEP を保管し、STL にメッシュ化して出力
   ▼
Blender (L2)      必要な場合のみ。スカルプトで質感・曲面調整
   │              STL 出力
   ▼
検査              水密・自己交差・肉厚・体積変化を確認
   ▼
スライサー (L3)   → 入稿パッケージ差し替え → 印刷
```

### 1. SaxSketch 側の準備（設計の凍結）

- パラメータ調整を完了し、シミュレーション結果（音程・音色レーダー）を確認。
- **.wproj を保存**する。手動編集に失敗してもここに戻れる唯一の復帰点。
- 「エクスポート / 入稿」で **STEP + 仕様書(spec.html)** を出力。
  仕様書の主要寸法表が外部編集時の「変えてはいけない寸法」の根拠になる。
- プロジェクトのメモ欄に凍結日時と出力先フォルダを記録しておく。

### 2. FreeCAD でのソリッド編集（L1）

設定画面で FreeCAD のパスを登録済みなら、エクスポート結果の「開く」から直接起動できる。

#### STEP は「面を選べる」表現で出る

マウスピースの STEP は、アプリ内プレビューや STL とは**別の表現**で書き出される。
プレビュー側は面がルールドロフトの微小パッチ（テナーで 2547 面）で、これを
そのまま STEP にすると面が1クリックで選べず、外周エッジへのフィレットも通らない。
STEP だけは同じ形を 1面ずつのプリミティブで張り直したもの（同 **60 面**、
微小エッジ 0 本）になる。形は同じで、面の張り方だけが違う。

そのぶん STEP の生成には十数秒かかる。STL だけのエクスポートは従来どおり速い。

#### フィレット/面取りの掛けどころ

- **半径は 0.2mm 以下**にすること。ティップの前縁は実物に合わせて面取りしてあり、
  前面が **0.25mm** しか無い。0.5mm を掛けると確実に失敗する。
- 掛けてよいのは**外周・シャンク外面・ビーク外面**のエッジ。
- **掛からないエッジがある**（FreeCAD がエラーを返す）。長さ 2mm 超の 83 本を
  1本ずつ試した実測:

  | 接している面 | 掛かる | 掛からない | 何のエッジか |
  |---|---|---|---|
  | 胴 + フェイシング/ビーク面 | 7 | 0 | 外周まわり。**ここは全部通る** |
  | 胴 + テーブル平面 | 3 | 1 | リード面の外周 |
  | 胴 + シャンク端面 / ボア | 2 | 0 | シャンクの口元 |
  | 胴 + 胴 | 0 | 4 | 母線を区切った継ぎ目。**接線連続なので掛ける意味が無い** |
  | ビークランプ + 胴 | 1 | 5 | 同上（ビーク面が胴へ接する所） |
  | 内部空洞どうし | 4 | 43 | 空洞・窓の縁。**元々編集禁止** |

  掛からない側は「編集してはいけない面」か「接線連続で角が無い所」のどちらかで、
  外周の角は取れる。空洞の断面は上下で別の指数を使って実物の天井アーチを
  再現しているため、赤道は接線連続でも曲率が不連続になる。

- **インポート**: `model.step` を開く（Part ワークベンチ）。
- **フィレット/面取り**: エッジ選択 → Fillet/Chamfer。外周エッジのみ。
- **名入れ（彫刻）**: Draft ワークベンチの ShapeString → Part Extrude →
  Boolean Cut。彫り深さは **0.4〜0.6mm**（浅いと印刷で潰れる）。
  文字高 4mm 以上推奨。位置はボディ側面（リガチャー座を避ける）。
- **装飾溝・平面カット**: スケッチ → ポケット。`min_wall`（既定 2mm）を下回らないこと。
- **出力**: STEP（再編集用に保管）と STL（Mesh ワークベンチ、
  偏差 0.02mm / 角度 5° 程度でメッシュ化）。

### 3. Blender でのメッシュ彫刻（L2・必要時のみ）

- STL をインポート（シーン単位を mm に設定。既定だと 1000 倍ズレる）。
- Sculpt モード（Dyntopo オン）で表面を調整。ビークの丸みなど。
- 終了前に **3D-Print Toolbox** アドオンで Non-manifold / 交差 をチェック。
- STL でエクスポート。

### 4. 検査（必須）

- 水密（watertight）・法線の一貫性・自己交差なしを確認。
  スライサーのエラーチェック、または Python なら:
  ```python
  import trimesh
  m = trimesh.load("model_edited.stl")
  print(m.is_watertight, m.is_winding_consistent, m.volume / 1000, "cc")
  ```
- **体積が編集前 ±数% に収まっているか**。大きく減っていたら削りすぎ
  （強度低下・音響乖離のサイン）。編集前の体積はエクスポート時の
  mesh_quality 表示（○○cc）が基準。
- スライサーでスライスプレビューし、薄壁・浮島がないか目視。

### 5. 入稿

- 入稿パッケージ(ZIP)内の STL を編集済みのものに差し替え。
- bom.csv / spec.html は元のまま同梱し、変更点（名入れ・フィレット等）を
  README に追記して印刷業者へ伝える。

## やってはいけないこと

- **手動編集後に SaxSketch のパラメータを変更して古い編集済みモデルを入稿する。**
  パラメータを変えたら形状が変わっている。STEP エクスポートからやり直す。
- 内容積が変わる編集（チェンバー拡大・バッフル削り）。音程・音色が
  シミュレーション表示と乖離する。これらは必ずパラメータで行う。
- `min_wall` を下回る彫り込み・ポケット。印刷破損・割れの原因。
- テーブル面への接触（サポート材の付着面にするのも避ける。印刷向きは
  仕様書の推奨条件を参照）。

## アプリ内サポート（実装済み）

ツールバーの「🛠 外部編集」からワークフロー全体をアプリ内で管理できる。

1. **凍結してエクスポート**: STEP/STL 出力と同時に凍結スナップショット
   （全パラメータ・実体積・日時）を記録。以後この形状が比較基準になる。
   設定画面で FreeCAD のパスを登録しておくと、エクスポート直後に
   `model.step` を自動で FreeCAD 起動・オープンする（未登録時は
   「🚀 FreeCADで開く」ボタンで手動起動）。
2. **編集済みモデルの取込・検証**: 外部編集した STL/STEP/3MF を取り込むと自動実行
   （ファイル選択ダイアログは凍結出力フォルダから開始する）:
   - 水密・法線・体積検査（体積 ±5% 超で警告）
   - **領域別偏差**: 凍結形状と表面距離を比較し、どの部位が
     どれだけ変わったかを部位名つきで表示（分解能 約±0.15mm）
   - **パラメータ逆算**: 断面・レイキャスト実測から主要パラメータ
     （ティップ開き・バッフル高さ・ボア径・ビーク高さ・窓長・スロート比・
     全長・ボディ径）を推定し、凍結値と照合して 一致/軽微/乖離 を判定。
     リード密着面や内部空洞の変更は自動で警告される
   - レポート確認後に「登録」すると .wproj に同梱され、以後の入稿パッケージは
     編集済みモデル（model_edited.stl）を使用する
3. **陳腐化警告**: 凍結後にパラメータを変更すると警告表示。陳腐化した状態での
   入稿エクスポートはブロックされる（パラメータを凍結値に戻すと解除）。
4. **表示切替**: 3Dビューアで「設計形状 / 編集済み」をタブ切替して確認できる。

### 逆算の限界（正直な注意）

- 座標系を移動・回転させた場合は逆算不能（警告のみ）。編集時は動かさないこと。
- カーブ種別・レール幅・チェンバー形状・コーク深さ等は形状から一意復元できない
  （「測定不能」と表示）。これらの変更は領域別偏差で間接検出される。
- バッフル高さは天井クランプの影響で過小評価されることがある（方向は正しい）。
