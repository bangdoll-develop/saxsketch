# バッフル形状の3型対応と断面編集（Stage D）

バッフル解説図の **ストレート型 / ステップ型 / カーブ型** を作り分けられるようにし、
中央断面を見ながらマウスで調整できるようにしたときの、実測と検証の記録。

## 着手前の状態 — 分類が噛み合っていなかった

`baffle_type` は 4 択（straight / rollover / step / curve）を持っていたが、実測すると
解説図の分類と対応していなかった。天井 y [mm]（tenor、ボア軸基準）:

```
  z     rollover  straight    step     curve
  0.00    -5.658   -5.658   -5.629   -5.658
 18.00    -5.549   -5.549   -4.706   -5.549   ← step だけ平坦部が 0.84mm 高い
 24.00    -3.652   -2.915   -4.495    0.310   ← curve が最も開いている
 26.00    -2.970   -2.037    2.528    1.845   ← step は 2mm の z で 7mm 立つ
```

- **既定の `rollover` が実は解説図のステップ型**（z=18mm まで棚が続く）。実測 WindyCity の
  天井そのもの。
- `straight` も同じ棚を持っていて、ストレートになっていない。
- `step` は平坦区間でも `v=0.06` 浮いていて、平坦部の高さが他型と 0.84mm ずれる。
- `curve` は `1−(1−t)^n` で **4型のうち最も早く開く**のに、`brightness._BAFFLE_BONUS`
  では最も明るい 0.24 が当たっていた（解説図の「メタリックでアグレッシブな音」とも
  合わない）。幾何と音響の向きが逆を向いていた。

## 作り直した形（`profiles._V_BUILDERS`）

天井は `C(z) = y0(σ) + (bore_r − y0)·v(σ)` を `shell_limit.top` で soft-min した形のまま。
**変えたのは `v(σ)` の作り方だけ**で、`y0`・床・半幅・断面指数には触っていない。

| 型 | v(σ) | 断面 |
|---|---|---|
| `step` | `r·S((σ−a)/W) + (1−r)·pchip(_CAVITY_C, warp_a(σ))` | 棚 → 段 → ボアへ |
| `straight` | `t = (σ−a)/(1−a)` | 一定勾配の直線 |
| `rollover` | 直線の肩を放物線フィレットで丸めたもの | ストレートの角落とし |
| `curve` | `t^n`（c≥0）/ `1−(1−t)^n`（c<0）、`n = 2^(1.6|c|)` | ふくらみ / スクープ |

4型とも **v(0)=0 / v(1)=1 / 単調非減少** を構成上満たす。単調性は「天井が z に対して
逆流しない」＝ロフト面が折り返さないための必要条件。

**既定は `step`**（テンプレート3種とも）。`baffle_plateau=0.36` / `baffle_step_rise=0`
のとき v は `pchip(_CAVITY_C, σ)` と **3.3e-16 で一致**する＝実測 WindyCity そのもの。
これが「型を作り直しても既定の形は動かない」担保で、`verify_base.py` の全項目
（気柱 18.686cc / レール 0.891mm / STEP 60面）が数値ごと変わらないことで裏を取っている。

## 調整ハンドルと可動域

| ハンドル | 型 | 可動域 | 根拠 |
|---|---|---|---|
| `baffle_height` | 全型 | 0–5mm | 既存 |
| `baffle_plateau` | step / rollover | 0.10–0.70 | 下の `_PLATEAU_RANGE` |
| `baffle_plateau` | straight / curve | 0.02–0.12 | 長い棚を許すと型でなくなる |
| `baffle_step_rise` | step | 0–0.85 | 段の切り立ち |
| `baffle_curvature` | curve | −1–+1 | +でふくらみ、−でスクープ |
| `rollover_radius` | rollover | 3–20mm | 肩の丸み |

**可動域が型で変わることが「型の形状的特徴を維持する」の実装**。UI は
`profiles.baffle_handles()` が返す `min`/`max`/`span` をそのまま使うので、
閾値がフロントに複製されない。

棚の下限を 0 にしないのは、σ < `_TIP_ROOF_SPAN`(=0.10) で天井が「レール基準 →
バッフル基準」へ乗り移るため。ここでランプを立てると天井がリード面を横切る z が
前へずれ、`tip_rail_width` の指定より細いレールになる（C-1b で立てた
「レール幅＝天井がリード面を突き抜ける z」の関係が壊れる）。実際、全型 × 全ハンドル極値 ×
3サイズで `|window_open_z − tip_rail_width| ≤ 0.044mm` に収まっている。

## 実測で分かった罠

- **スクープ側に `t^m` (m<1) を使ってはいけない。** t=0 で傾きが発散する。`c=−1` だと
  棚の直後 0.7mm で天井が 3.4mm 立ち上がる垂直壁になり、ルールドロフトの弦誤差が
  **1.41mm** に達した。`1−(1−t)^n` なら t=0 の傾きが n で有限（c=−1 で 0.87mm/mm）。
- **急な天井は等間隔ステーションでは表現できない。** `_STATION_DZ=1.6mm` のままだと
  弦が内側へ落ちる（`baffle_step_rise=0.85` で 0.54mm）。中点の弦誤差で二分する
  適応分割（`_refine_for_roof`）を入れた。許容値 `_ROOF_CHORD_TOL=0.14mm` は
  **実測形状自身の弦誤差 0.132mm のすぐ上**に置いてある。下げると既定の形が変わり、
  C-1b の校正ごと作り直しになるため。既定ではこの分割は一度も発動しない
  （ステーション 43 本・STEP 60 面のまま）。
- **レイを x=0 ちょうどで飛ばすと当たりを取りこぼす。** 形状は左右対称で断面点列も
  対称に作られるので、x=0 には三角形の稜線が並ぶ。真上へ飛ばすと天井を素通りして
  外形に当たり、90点中 4〜9 点が 6mm 誤差として出た。0.15mm ずらして測る
  （天井の横アーチはそこでは 0.001mm も動かない）。
