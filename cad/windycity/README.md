# 実物準拠マウスピース ベース形状（SaxSketch 新ベース）

SaxSketch のマウスピース ベース形状を、実在のマウスピース
**WindyCity Tenor .100" Long Shank**（`WindyCity-Tenor-72-100-LS.3mf`）の実測から
起こし直した。ここにあるのは「実測 → 構成式化 → 検証」の一式。

形状定義そのものは `saxsketch/instruments/saxophone/components/profiles.py` にある
（このフォルダは実測・検証・目視確認のための道具）。

## 実測で判明した構造（旧モデルとの違い）

| | 旧 SaxSketch | 実物 |
|---|---|---|
| テーブル面 | ボア軸に平行な定数平面 `-0.40·body_dia` | **ボア軸に対し 4.18° 傾いた平面**（平面度 rms 0.035mm） |
| 外形断面 | 真円回転体（プロファイルが別物） | 真円回転体だが**プロファイルが実測と一致**。見かけの卵形はテーブルカットの結果 |
| ビーク | 3点 smoothstep 曲線 | **18.0° の直線ランプ**＋**半径 25mm の円筒面**、0.43–0.53·踵 で胴へブレンド |
| バッフル天井 | リード面基準の上昇曲線 | **ボア軸に平行な平面**が窓の 44% まで続き、直線ランプ→指数ブレンドでボア天井へ |
| チェンバー | 膨らみ＋スロート狭窄が既定 | **どちらも無い**。断面積が単調にボアへ開く（既定比 1.0） |
| ウィンドウ | 幅の上限を**テーブル平面**の弦で判定 | 上限は**リード面**（テーブル＋フェイシング持ち上がり）の弦。断面はスロットが直立壁 |

### ウィンドウの作り直し（Stage A-2）

初版は先端で窓が点に潰れていた。原因は2つとも「窓の縁がどの面にあるか」の取り違い:

1. 窓幅の上限をテーブル平面の弦で見ていた。ティップ側はフェイシングが
   リード面を最大 2.4mm 持ち上げているので、実際に使える弦はもっと長い
   （z=1.2 でテーブル平面 4.1mm に対しリード面 12.2mm）。→ `reed_chord()`
2. 断面がスーパー楕円だったため、リード面の高さで幅が設計値の 78% に痩せていた。
   実物のスロットはレール厚を貫く**直立の側壁**なので、断面の下端を平坦・直壁にした。

あわせて窓の後端も、床を段差で上げると内部に垂直な棚ができるためランプに変更し、
閉口後はスロットの細りを止めてチェンバー断面へ戻す（鍵穴形の残りを解消）。

座標系をボア軸に正すと **ティップ開き実測 2.65mm ≒ 刻印 .100"(2.54mm)**。
旧軸（PCA のまま・約1°ずれ）では 3.1mm と過大に出ていた。これが「軸の取り方が
すべての実測を汚す」ことの証拠になっている。

## 新しい構成式の要点

- テーブル平面の位置は魔法定数ではなく **「ティップが z=0 に立つ」** で決まる
  （`-r(0) = table(0) + tip_opening`）。実測と 0.01mm で一致する。
- 踵（最大径＝テーブルが消える位置）は `heel_z = (全長 − シャンク長)/(1+肩比)`。
  テナーで 79.0mm となり、**規格リード全長 78mm と一致**する（照合カードも「一致」）。
- ビークの傾きは `beak_height`（バイトポイントでのテーブル面からの高さ）と
  ティップ端の頂点から一意に解ける。実測 17.99°（実物 18.0°）。

| テーブル傾斜 | −4.25° | −4.17° |

| **ウィンドウ幅**（z=6–38） | 実物との差 平均 **0.21mm** / 最大 0.40mm | — |
| ウィンドウ開口 z 範囲 | 3.0–41.0 | 4.5–41.5 |

tenor / alto / soprano の3サイズとも単一ソリッドで生成でき、`simulate()` も通る。

## 見かた

`base_tenor.FCStd` を FreeCAD で開くと、新ベース ソリッドと実物メッシュ
（`WindyCity_Reference`）が同じ座標系で重なっている。メッシュを選択して
表示プロパティの `Transparency` を上げると差が見やすい。

## 未追従（Stage B で直す）

新形状に他コンポーネントがまだ追いついていない。判定カードが正しく警告を出している。

- **リガチャー**: 内周がテーブル傾斜を知らないため「リードが入りません」警告。
  `ligature_profiles.py` を傾斜テーブルへ追従させる必要がある。
- **ネック**: 実測ボア径 17.0mm に対しテナー neck の `tenon_od` 17.8＋コルクで 19.4mm。
  **物理的に挿さらない**ので、ネック側の再フィットが要る（照合カードが「乖離」で検出）。
- 逆算（`measure.py`）・仕様書 SVG・音響 Tier1 の基準値も旧前提のまま。
