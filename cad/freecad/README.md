# FreeCAD 用 マウスピース ベース形状 3案

サクソフォン マウスピースの「ベースとなる基本形状」を、FreeCAD で開いて編集できる形で
**3 つの構築手法**で用意したものです。各部名称（ティップレール／ウィンドウ／サイドレール／
ウォール／テーブル／ビーク／ティップオープニング／フェイシング／チェンバー／バッフル／
スロート／ボア／シャンク）はどの案にも反映しています。どれをプロジェクトの新ベースに
採用するか、FreeCAD で開いて見比べて選んでください。

## ファイル

| ファイル | 内容 |
|---|---|
| `variant_a_primitives.FCStd` / `.py` | **A案** プリミティブ＋Boolean＋Spreadsheet |
| `variant_b_sketch_loft.FCStd` / `.py` | **B案** 曲線（線分・円弧・スプライン）＋Revolve＋Loft |
| `variant_c_sections.FCStd` / `.py` | **C案** 実断面ロフト（アプリ幾何と一致） |
| `mp_presets.py` | 3案共通のサイズ別パラメータ（soprano / alto / tenor） |

`.FCStd` … FreeCAD でダブルクリックすればそのまま 3D 表示・確認できる完成モデル。
`.py` … その FCStd を生成したパラメトリック スクリプト。先頭のパラメータを書き換えて
再実行すると FCStd を作り直せる。

既定サイズは **tenor**。全案とも単一の水密ソリッドで、全長・外径・ボア径が
テンプレート校正値に一致することを確認済み。

## 座標系（全案共通・アプリ準拠）

- **Z**: 軸方向。`z=0` がティップ（先端）、`z=overall_length` がシャンク端。
- **Y**: `+Y` がビーク（上面）、`−Y` がテーブル（リード側）。
- **X**: 幅方向。
- 単位はすべて **mm**。

## 3案の違い（構築手法）

### A案 — プリミティブ＋Boolean＋Spreadsheet（数値編集が最易）
テーパ円柱（`Part::Cone`）・円柱・箱を Boolean で組んだ素直な構成。寸法を
**Spreadsheet「params」** に集約し、主要寸法をプリミティブへ **式束縛**してあるので、
FreeCAD 上で params のセルを書き換えると 3D 形状がその場で再計算される（例: `bore_r`
セルを変えるとボアがライブで太る／細る）。
意匠を掴むための**近似**モデル: チェンバー＝箱、窓＝スロット、テーブル＝平面。
スーパー楕円チェンバー・馬蹄・実段差バッフル・フェイシングカーブは表現しない。

### B案 — 曲線＋Revolve＋Loft（CAD 王道・滑らかな曲面）
外形を制御点を通す **B スプライン断面の回転体**、ビーク／テーブルのカットを
**B スプライン輪郭**で構成した曲面ベースの案。空洞は堅牢性のため断面ロフト
（後述 C 案と同じ断面）を用いる。外径はスプラインの性質上わずかに膨らむ
（tenor で径 27.5→約 28.2mm）。滑らかな面質を優先したいとき向き。

### C案 — 実断面ロフト（アプリ幾何と一致・最も実物忠実）
アプリ本体（SaxSketch）の断面プロファイル定義 `profiles.py` をそのまま読み込み、
外形・ビーク／テーブルのカット曲線・**96 点断面の内部空洞**を再構築する。生成形状は
アプリの build123d 版と幾何一致し、内容積もカタログ値（tenor で約 19.637cc）に一致。
馬蹄チェンバーやステップ実段差バッフルなどの実形状もそのまま出せる。厳密さが要るとき向き。

## 編集のしかた

- **サイズを変える**: 各 `.py` 先頭の `SIZE = "tenor"` を `"alto"` / `"soprano"` に変更して再実行。
- **A案をその場で数値編集**: FreeCAD で `.FCStd` を開き、Spreadsheet「params」のセルを編集 → 再計算。
- **個別寸法を変える（B/C案、A案の複雑部）**: `.py` 先頭付近のパラメータ上書き行
  （`p["baffle_type"]=...` などのコメント例）を編集して再実行。
- **再生成コマンド**（ヘッドレス）:
  ```
  "C:/Program Files/FreeCAD 1.1/bin/freecadcmd.exe" variant_c_sections.py
  ```
  FreeCAD の GUI からは「マクロ → マクロを実行」で各 `.py` を選んでも生成できます。

## 限界（正直に）

- **A案・B案は近似**。プリミティブ／簡易曲線ではスーパー楕円チェンバー・馬蹄・
  フラットサイドウォール・ステップ実段差・フェイシングカーブを厳密再現しません。
  **C案のみアプリ幾何と厳密一致**します。
- **Spreadsheet ライブ編集は A案のみ**。B案・C案は `.py` を書き換えてマクロ再実行で再生成
  （`.FCStd` は静的スナップショット）。
- 形状生成のみが対象で、音程・音響シミュレーションは含みません。寸法はテンプレートの
  校正値で、実物へ寄せるにはノギス実測での上書きが本筋です。

## 生成元

パラメータ値は `saxsketch/instruments/saxophone/templates/{soprano,alto,tenor}.json` の
`mouthpiece` ブロック由来。C案が参照する形状定義は
`saxsketch/instruments/saxophone/components/profiles.py`。
この `cad/freecad/` フォルダはアプリ本体とは独立した FreeCAD 用の成果物で、
アプリの動作には影響しません。
